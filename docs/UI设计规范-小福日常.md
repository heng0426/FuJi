## 1. 需求解析

| 字段 | 内容 |
|------|------|
| `project_type` | 工具 / 健康记录（单宠日常） |
| `target_platform` | Android 原生（Compose），360dp 基准，竖屏单手操作 |
| `user_persona` | 养橘猫"小福"的铲屎官；每日高频记录喝水/喂食，低频记录体重/驱虫/疫苗/异常 |
| `core_tasks` | ① 3 秒内记一笔（喝水/喂食）② 一眼看清今日状态与到期事项 ③ 按日期/类型回查历史 |
| `brand_tone` | 温暖、干净、可靠；橘白奶油感，不幼稚、不冷硬 |
| `constraints` | Material 3；深色模式；minSdk 28；WCAG AA 文本对比度；单手拇指可达 |

**设计原则（按优先级）**
1. **速度优先**：最高频动作（喝水、喂食）在首页一屏内、拇指区内完成，弹窗预填上次值。
2. **一眼可读**：数字（ml / 份·克 / 斤）是主角，标签退后；一屏不出现超过 3 种强调色。
3. **情绪克制**：橘色只用于主操作与选中态，大面积留给奶油底与白卡，避免"满屏橘"。
4. **一致性**：六类记录各有一个固定图标 + 固定语义色，全 App 不换。

## 3. 组件规格卡

| 组件 | 规格 | 状态与交互 |
|------|------|-----------|
| `OverviewCard` 今日概览 | 白卡 20dp 圆角；左栏喝水（34sp 数字 + ml 单位），竖分割线，右栏主粮、最近体重常驻；加餐仅当日有记录时插入 | 加餐行淡入 + 垂直展开，消失时淡出 + 收起；体重行可点 → 体重录入 |
| `DueBar` 到期提醒条 | 高 40dp，浅橘/类型色容器，14dp 圆角，左图标 + 文案 + 右 chevron | 仅 T-3 内出现；可点 → 记录页对应类型 |
| `QuickTile` 快捷按钮 | 74dp 高，四等分，18dp 圆角；图标 22dp + 标签 11.5sp | 喝水为主操作（橘底深棕字）；单击直接打开对应弹窗，无长按快捷记录 |
| `TimelineItem` 时间线条目 | 行高 ≥56dp；36dp 圆角图标底 + 主文案 + 时间（右，tabular）；点击区 12dp 圆角、图标距左/上/下 8dp | 点击 → 详情；长按 → 多选；行间 1px 虚线分割；选中行浅橘底 + 圆形勾选 |
| `Sheet` 底部弹窗 | 顶部 26dp 圆角，把手 36×4dp，内边距 20dp；主按钮高 50dp | 下滑/点遮罩关闭；主按钮为唯一强调 |
| `NumberField` 数字输入 | 44sp 数字 + 单位；`surface-2` 底，16dp 圆角 | 预填上次值；数字键盘；上下限软校验 |
| `Stepper` 步进器 | − / 值 / +，按钮 36dp（点击区 44dp） | 份数 **1–20 整数步进**；克重 1g 步进；长按连续 |
| `Chip` 标签 | 高 34dp，999dp 圆角，左右 14dp | 未选：白底描边；选中：浅橘容器 + 深棕字 |
| `CalendarCell` 日历格 | 42dp 高；数字 31dp 圆形（38dp 圆形点击区）；下方 4dp 标记点 | 有记录=灰点；异常=红点；到期=**驱虫紫环 / 疫苗青环**（不画到期点）；选中=橘底；今天=主色环 |
| `SettingRow` 设置行 | 高 56dp，左图标容器 32dp，右值 + chevron | 整行可点；开关用 M3 Switch |
| `SelectionTopBar` 多选顶栏 | 高 52dp，左“已选 N 条”，右“取消 + 删除” | **固定在列表上方吸顶**，滚动不消失；批量删除二次确认 |
| `ListRow` 列表按压 | `roundedRowClickable`：12dp 圆角、按下底色、统一涟漪 | 深色下主色按压层；支持长按（更多/补记/记录/标签） |

## 5. 前端实现指引（Compose）

| 项 | 建议 |
|----|------|
| 主题文件 | `Theme.kt` 内维护明暗 `ColorScheme`、`RecordStyle` 与 `LocalAppDarkTheme`；`ThemeMode.kt` 管理跟随系统/浅色/深色与 SharedPreferences 持久化 |
| 语义色 | 新增 `RecordTypeColors` 数据类（icon: ImageVector + 前景/底色），供时间线、日历、标签共用，禁止页面内散落颜色常量 |
| 图标 | Material Symbols Rounded；以 **vector drawable** 引入 7 个记录图标 + Tab 图标，避免整包 `material-icons-extended` 增加 APK 体积；图标语义见 §2.3 |
| 数字 | 使用 `FontFeatureSettings("tnum")` 或等宽数字，避免数字跳动 |
| 触控 | 所有图标按钮加 `minimumInteractiveComponentSize()`；列表行统一 `Modifier.roundedRowClickable(onClick, onLongClick)`（12dp 圆角 + 按压反馈）；长按用 `combinedClickable` |
| 无障碍 | 图标按钮补 `contentDescription`；文本对比度按 §2 表；支持系统字号缩放（sp） |
| 深色 | 全部颜色走 `MaterialTheme.colorScheme` 与 `recordStyle(type)` 的 dark 分支；判断主题用 `LocalAppDarkTheme.current`，不要用 `isSystemInDarkTheme()`，否则强制深色会取错色板 |
| 日历 | 月历使用 `HorizontalPager` 实现跟手翻页；月份状态以 `currentPage` 同步；日期格标记与到期信息分离 |
| 弹窗状态栏 | Activity 的 `attachBaseContext` 按外观设置强制资源 `uiMode`（SYSTEM 除外），使 ModalBottomSheet/Dialog 继承正确明暗主题，状态栏图标不会在深色弹窗时变暗 |
