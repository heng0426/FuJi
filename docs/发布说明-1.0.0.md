## 本版内容

首个正式版本，覆盖单宠日常记录完整闭环：

- **六类记录**：喝水、主粮/加餐、体重、驱虫、疫苗、异常；新增/编辑/详情/删除完整。
- **今日首页**：喝水与进食汇总、最近体重、到期提醒、快捷记录、按日时间线、多选批量删除。
- **喂食**：整数份数、份数/克重记忆、内置与自定义预设、加餐标签。
- **日历**：跟手横向翻月、记录/异常小点、驱虫紫环/疫苗青环、到期日首条信息、手动日期跳转、今天按钮。
- **记录页**：类型筛选、标签拖拽排序、驱虫/疫苗倒计时卡、多选删除。
- **我的**：宠物档案、驱虫周期、提醒设置、外观三态（跟随系统/浅色/深色）、体重趋势。
- **提醒**：WorkManager 每日检查、通知权限引导、提醒小时可配置；已由用户真机验证到点触发。
- **深色模式**：全页面适配；修复底部弹窗导致状态栏图标不可读。
