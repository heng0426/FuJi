# 小福日常 1.1.0 发布说明

> 发布日期：2026-11-23
> 版本：`1.1.0`（versionCode 11）
> 安装包：`dist/小福日常-v1.1.0.apk`（自测签名，覆盖安装保留数据，与 1.0.0 同证书）
> 平台：Android 9+（minSdk 28），compileSdk / targetSdk 37

## 本版内容

### 新增
- **数据备份与恢复**：「我的」页可导出 ZIP 备份包（`backup.json` + 全部照片），恢复为替换式并经校验（schema 版本 / 枚举 / 外键 / 文件名白名单）与二次确认；换机、清数据前必备。
- **药品名 / 疫苗名称常用标签**：默认海乐妙、大宠爱、福来恩、爱沃克、博来恩与猫三联、狂犬疫苗、妙三多；点击填入、长按删除（确认弹窗，含默认项）、可自定义添加；随备份导出/导入同步。
- **跳转日期多格式**：日历手输跳转兼容 `2026-11-23`、`2026/11/23`、`2026年11月23日`，并提供「从日历选择日期」（系统 DatePicker）。
- **日历月份标题跟手**：拖动翻月时标题随网格越过中线即时切换。

### 改进
- 驱虫/疫苗页修改记录日期后，下次到期按周期自动平移（未手动改写的自动值；手动改写过的保持不变；疫苗按 1 年/3 年快捷值平移）。
- 记录页类型 chips 收窄（30dp 高 / 11dp 边距 / 11sp），拖动排序时被挤走的 chip 有平滑让位动画。
- 编辑档案弹窗：键盘弹出时取消/保存按钮固定在键盘上方，字段区可滚动。
- 显式 `adjustResize`，消除异常编辑页键盘弹出时整页上移。

### 无障碍
- TalkBack 语义补齐（返回/新增/删除/减少/增加、日历格完整日期+状态朗读）。
- 触控目标 ≥44dp（步进按钮、日历箭头、跳转行；chips 30dp ≥ WCAG AA 24dp）。
- 动态字体 2.0× 风险修复（步进值宽度、备注框内滚动）。

### 其他
- 锁定竖屏（360dp 竖屏单手设计，横屏/大屏适配留待 v2 评估）。

## 验证摘要

- P1 功能与 R8 真机反馈修复：**真机验收通过（用户确认，2026-11-23）**——备份导出/恢复、chips 与拖拽、档案弹窗键盘、异常页键盘、到期联动、标签增删确认。

## 已知限制

- 自测签名，不可上架应用商店。
- 批量删除为二次确认，不提供撤销；单条删除支持 Snackbar 撤销。
- 主题偏好（SharedPreferences）不在备份范围内，恢复后沿用当前外观设置。
- TalkBack/动态字体为代码级修复 + 真机抽查，未做完整无障碍走查。
