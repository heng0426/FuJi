# 小福日常 1.2.0 发布说明

> 发布日期：2026-11-23
> 版本：`1.2.0`（versionCode 12）
> 安装包：`dist/小福日常-v1.2.0.apk`（自测签名，覆盖安装保留数据，与 1.1.0 同证书）
> 平台：Android 9+（minSdk 28），compileSdk / targetSdk 37

## 本版内容

### 新增

- **桌面小组件**：4×2 组合（喝水 + 喂食）与 2×2 独立喝水/喂食；卡片内直接确认，不弹窗、不跳转；浅/深色跟随 App；写入、删除、改档案、恢复备份、回前台、每天 00:05 与 30 分钟周期刷新。
- **近 7 天柱状图**：今日页查看喝水/主粮最近 7 天，今天高亮，按最大值归一，显示今天与日均。
- **异常照片墙**：记录页入口，三列网格按时间倒序；点按进入全屏预览，可跳回对应异常记录。
- **照片全屏预览**：左右滑动切换、双指 1–5× 缩放、放大后拖动、双击 2.5×/还原；顶部序号、底部异常提示；全屏覆盖层与主界面共用窗口，状态栏区域纳入显示。
- **兽医就诊记录**：医院、医生、诊断、费用、备注与最多 3 张照片；接入今日「更多」、日历补记、记录页筛选/时间线/详情与日历圆点。

### 改进

- 详情缩略图、照片墙与预览统一为应用内全屏层，修复状态栏色差与图标不生效。
- 备份 schema 升到 2，新增就医字段；仍可导入 v1 备份。
- 组件跨零点：00:05 定时刷新，今日汇总不再最多滞后半小时。

### 数据

- 数据库 v1 → v2：`records` 新增 `vet_hospital` / `vet_doctor` / `vet_diagnosis` / `vet_cost_yuan` 四个可空列，旧数据不受影响。

## 验证摘要

- `assembleDebug` / `assembleRelease` / `assembleDebugAndroidTest` 通过。
- 单元测试：周聚合、00:05 排期（当天未到 / 已过 / 白天）。
- 小组件 8 项 RemoteViews 渲染测试沿用；照片预览与照片墙的完整手势回归待真机走查。
- 覆盖安装（`adb install -r`）保留数据；本次包含 DB v2 迁移。

## 已知限制

- 自测签名，不可上架应用商店。
- 小组件选择器仍显示应用图标（`previewImage` 未补）。
- v1 应用无法读取包含「就诊」记录的 1.2.0 备份。
- 照片墙仅展示异常记录的照片。
