# 小福日常 1.3.0 发布说明

> 发布日期：2026-11-26
> 版本：`1.3.0`（versionCode 13）
> 安装包：`dist/小福日常-v1.3.0.apk`（自测签名，覆盖安装保留数据，与 1.2.0 同证书）
> 平台：Android 9+（minSdk 28），compileSdk / targetSdk 37

## 本版内容

### 新增

- **悬浮液态玻璃底栏**：底栏改为 iOS 风格悬浮胶囊，内容铺满全屏；下层对背景做高斯模糊采样（API 31+），叠玻璃底色、描边渐变与顶部柔光；选中项为独立胶囊并带轻微缩放；系统模糊不可用时退化为实底，保证文字可读。
- **喝水「水瓶 / 水碗」换算**：弹窗除直接填量外，可分别按水瓶、水碗填「上次剩余 / 本次剩余」，差值即本次喝水量；只填上次剩余时仅记住数值、不写记录；两种来源各自记住上次剩余，互不覆盖；上次选择持久化。
- **近 7 天体重折线**：近 7 天卡新增体重模式，按天取最后一次称重绘制，底部显示最近体重与 7 天变化。
- **近 7 天按天滑动**：卡片改为 7 天滑动窗口，跟手拖动、松手按速度惯性并吸附到整日；右滑看更早、左滑回到今天；标题显示当前区间，底部按窗口重算日均 / 体重变化；至少保留两个窗口（14 天）可回看。
- **底栏参数调试面板**：我的页入口，21 项参数（尺寸、圆角、透明度、模糊半径等）实时生效并持久化；本版已按验收结果把数值写为默认值。

### 改进

- 今日：到期卡可点击，按 `recordId` 打开来源驱虫 / 疫苗记录详情；列表键改用 `recordId`，内驱外驱同日到期不再键冲突。
- 今日：喂食与加餐分开记忆份数与克重，互不覆盖；默认值按餐类回退到最近一条同类记录。
- 今日：右上角新增柱状图按钮，控制近 7 天卡显示，状态记在本机。
- 我的：删除「数据都在本机」提示卡；体重录入移除精度提示。
- 移除三个无功能的装饰入口。
- 近 7 天柱高基准随窗口与模式即时重置，切换喝水 / 主粮不再溢出；窗口最大值变小时平滑回落。

### 修复

- 水瓶与水碗互切时输入框闪烁。
- 近 7 天左右方向相反、跨月翻页后选中日错位。
- 日历翻月再翻回时不重新选日（effect 捕获首帧月份）。
- 近 7 天记录不足时无法回拖（现至少保留两周）。

### 数据

- 数据库仍为 v2，本版无结构变更，无迁移。
- 备份 schema 不变，1.2.0 备份可直接导入。

## 验证摘要

- `assembleRelease` 通过，产物为 `dist/小福日常-v1.3.0.apk`。
- 单元测试：`WaterSourceTest`（水瓶 / 水碗差值、只填上次剩余、空值与倒挂）、`WeekStatsTest`（周窗口、体重按天取末次、空白天、类型过滤）。
- 覆盖安装（`adb install -r`）保留数据，与 1.2.0 同证书。
- 真机（M2011K2C / Android 14）由用户手动验收交互与视觉。
