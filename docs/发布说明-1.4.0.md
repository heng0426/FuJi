# 小福日常 1.4.0 发布说明

> 发布日期：2026-11-27
> 版本：`1.4.0`（versionCode 14）
> 安装包：`dist/xiaofu.apk`（GitHub Release 固定资源名）、`dist/小福日常-v1.4.0.apk`
> 版本清单：`dist/update.json`
> 平台：Android 9+（minSdk 28），compileSdk / targetSdk 37

## 重要：签名已更换，本版需要卸载重装一次

1.3.0 及更早的 release 包复用 Android SDK 的 `debug.keystore` 签名；1.4.0 起改为专用发布证书
（`CN=XiaoFu Daily`，4096 位 RSA，有效期 10000 天）。系统要求升级包与已安装包的签名证书一致，
因此本次无法直接覆盖安装：

1. 旧版进入「我的 → 导出备份」，保存 ZIP 到手机文件（记住位置）。
2. 卸载旧版。此步骤会清空本地数据库与照片。
3. 安装 `dist/xiaofu.apk`。
4. 打开新版，「我的 → 从备份恢复」选择刚才的 ZIP。

**从 1.4.0 起，后续版本可直接在应用内覆盖升级，不再需要卸载。**
证书 SHA-256 指纹：`fd5827b69e4a0d2942ec1420f15a9741cf3e9f31471f2835501edbb307fd27ee`，
建议与证书文件一起离线留存，用于核对后续安装包来源。

## 本版内容

### 新增

- **应用内升级**：「我的 → 关于」新增检查更新；发现新版本时展示版本号、包大小与更新说明，
  提供「立即更新 / 稍后 / 跳过此版本」，不做强制更新。
- **下载与校验**：主源 GitHub Releases，备源接口已预留（`update.json` 的 `mirrors`）。
  下载后依次校验大小、SHA-256、包名、签名证书摘要，任一不符即中止，不进入系统安装器。
- **每日检查与提醒**：每天 10:00 检查一次（与驱虫提醒 09:00 错开），有新版本发通知；
  开关默认开启，可在「关于」内随时关闭，关闭后同时取消后台任务。
- **升级前自动备份**：点击更新后，先把当前数据导出到「下载/小福日常」，卸载后仍可找回。
- **安装引导**：未授权「安装未知应用」时给出对应系统路径；安装失败按错误码给出可读文案
  （拦截、取消、空间不足、签名冲突、版本不兼容）。

### 改进

- 「关于」由 AlertDialog 改为底部弹层，容纳版本、检查更新、提醒开关与数据说明。
- 版本号与发布信息统一由根目录 `version.properties` 提供，避免 `versionCode` 与 Git tag 漂移。
- 新增 `releaseArtifacts` 任务：一条命令产出 APK、SHA-256 与 `update.json`。

### 数据

- 数据库仍为 v2，本版无结构变更，无迁移。
- 备份 schema 不变（v2），1.2.0 / 1.3.0 备份可直接导入。

## 验证摘要

- `assembleRelease`、`releaseArtifacts` 通过，产物已写入 `dist/`。
- 单元测试 `testDebugUnitTest` 通过（WaterSourceTest、WeekStatsTest、WidgetScheduleTest）。
- `apksigner verify` 确认签名证书为 `CN=XiaoFu Daily, OU=Personal, O=FuJi, C=CN`。
- `aapt2 dump badging` 确认 versionCode 14、versionName 1.4.0，权限含 INTERNET 与
  REQUEST_INSTALL_PACKAGES。
- 真机链路（下载 → 校验 → 授权 → 安装 → 数据完整）待在完成一次卸载重装后验证。

## 已知限制

- 本次迁移必须卸载重装，升级前请务必备份。
- 国产 ROM 需手动允许「安装未知应用」；华为/荣耀需关闭纯净模式，三星需关闭 Auto Blocker。
- 每日检查受厂商后台策略影响可能延后，手动入口始终可用。
- GitHub 直连速度受网络环境影响；备源字段已预留，后续可加国内镜像。
- 应用内不支持降级；跨数据库版本回滚需卸载后装回旧版并导入升级前的备份。

## 安装

```bash
adb install -r dist/xiaofu.apk
```

首次从 1.3.0 迁移时 `-r` 会因签名不一致失败，请按上文先备份、卸载，再安装。
