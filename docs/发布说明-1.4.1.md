# 小福日常 1.4.1 发布说明

> 发布日期：2026-11-27
> 版本：`1.4.1`（versionCode 15）
> 安装包：`dist/xiaofu.apk`、`dist/小福日常-v1.4.1.apk`
> 版本清单：`dist/update.json`
> 平台：Android 9+（minSdk 28），compileSdk / targetSdk 37

## 为什么这么快发一版

1.4.0 发布后实测：在部分网络下 `github.com` 的 443 端口不可达（TCP 连接超时），
而 `api.github.com`（约 0.6 s）与 `objects.githubusercontent.com`（约 0.8 s）正常。
1.4.0 把清单地址硬编码在 `github.com`，因此这类网络下检查更新会直接失败。

1.4.1 增加第二条通道，按可用性自动切换。

## 本版内容

### 修复

- **检查更新增加 API 回落**：先试 `releases/latest/download/update.json`；
  失败后改走 `api.github.com/repos/heng0426/FuJi/releases/latest`，
  按资产名定位 `update.json` 与 `xiaofu.apk`，再经 `objects.githubusercontent.com` 下载。
- **安装包优先走已证明可达的通道**：清单若来自 API，则 APK 也先用 API 资产地址，
  避免再次等待一次必然失败的超时。
- **超时收敛**：连接超时由 10 秒降为 6 秒，直连不可用时能更快切换。

### 不变

- 数据库 v2，无迁移；备份 schema 不变。
- 四重校验（大小 / SHA-256 / 包名 / 签名证书）与安装确认流程不变。
- 签名不变，可与 1.4.0 直接覆盖安装，数据保留。

## 验证摘要

- `releaseArtifacts` 构建通过，`testDebugUnitTest` 通过。
- 手机侧实测网络：`github.com` 443 超时；`api.github.com` 200（0.6 s）；
  `objects.githubusercontent.com` 可建立 TLS（0.8 s）。
- `update.json` 的 `sha256` 与 APK 实测一致（见发布页资产）。
- 真机全链路（检查 → 下载 → 校验 → 授权 → 安装）待本版装上后验证。

## 安装

1.4.0 可直接覆盖安装：

```bash
adb install -r dist/xiaofu.apk
```

或在手机上用文件管理器打开 APK 安装。装好后进入「我的 → 关于 → 检查更新」，
应显示「已是最新」；待 1.4.2 发布时即可验证完整的下载与安装链路。

## 已知限制

- `api.github.com` 匿名访问有每小时 60 次的限额；个人日常检查与下载远低于该阈值，
  若触发 403，稍后重试即可。
- 应用内不支持降级；跨数据库版本回滚需卸载后装回旧版并导入升级前的备份。
