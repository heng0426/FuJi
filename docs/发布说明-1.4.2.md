# 小福日常 1.4.2 发布说明

> 发布日期：2026-11-27
> 版本：`1.4.2`（versionCode 16）
> 安装包：`dist/xiaofu.apk`、`dist/小福日常-v1.4.2.apk`
> 版本清单：`dist/update.json`
> 平台：Android 9+（minSdk 28），compileSdk / targetSdk 37

## 本版内容

### 新增

- 「关于」页的「检查更新」下方显示**上次检查时间**（例：`上次检查 11-27 21:20`），
  未检查过时显示「尚未检查」。用来确认每日 10:00 的后台检查是否真的在跑，
  也便于判断网络通道是否正常。

### 说明

- 本版同时用于验证 `1.4.1 → 1.4.2` 的完整应用内升级链路：
  检查 → 下载 → 四重校验 → 授权 → 安装 → 数据保留。
- 数据库仍为 v2，无迁移；备份 schema 不变。
- 签名不变，可与 1.4.1 直接覆盖安装。

## 验证摘要

- `releaseArtifacts` 构建通过，`testDebugUnitTest` 通过。
- 清单与 APK 的 SHA-256 由构建任务生成，见发布页资产。
- 升级链路在真机上验证（结果见仓库验收记录）。

## 已知限制

- `api.github.com` 匿名访问限 60 次/小时；个人使用远低于该阈值。
- 应用内不支持降级；跨数据库版本回滚需卸载后装回旧版并导入升级前备份。
