# 小福日常 1.4.3 发布说明

> 发布日期：2026-11-27
> 版本：`1.4.3`（versionCode 17）
> 安装包：`dist/xiaofu.apk`、`dist/小福日常-v1.4.3.apk`
> 版本清单：`dist/update.json`
> 平台：Android 9+（minSdk 28），compileSdk / targetSdk 37

## 背景

1.4.2 在真机验证升级链路时暴露了两个体验缺陷：安装被取消后弹窗停在「正在打开安装器」不动；
点「重试」会从头再下载一次 20 MB（本网络下约 15 分钟）。本版修复这两点。

## 本版内容

### 修复

- **失败不再卡死**：安装会话回调把界面切到「更新未完成」，给出失败原因与「重试 / 关闭」。
- **重试复用安装包**：重试与授权返回都优先使用已校验的缓存包，尺寸与版本一致时不再重复下载。
- **授权返回兜底**：回到前台时若仍处于「待授权」且权限已授予，自动继续安装；
  兼容不派发 `ActivityResult` 的定制 ROM。
- **授权提示更明确**：说明部分机型会先打开应用列表，需要在列表中选中「小福日常」。

### 不变

- 数据库 v2，无迁移；签名不变，可覆盖安装。
- 四重校验与系统安装确认流程不变。

## 验证摘要

- 构建通过，`testDebugUnitTest` 通过。
- 真机：1.4.2 → 1.4.3 升级链路（下载、校验、授权、安装）见验收记录。

## 已知限制

- GitHub CDN 在本网络实测约 22–40 KB/s，20 MB 安装包约需 10–15 分钟；
  已有 `mirrors` 字段，后续接入国内源可显著改善。
- 应用内不支持降级。
