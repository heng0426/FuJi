# 小福日常 1.4.4 发布说明

> 发布日期：2026-11-27
> 版本：`1.4.4`（versionCode 18）
> 安装包：`dist/xiaofu.apk`、`dist/小福日常-v1.4.4.apk`
> 版本清单：`dist/update.json`

## 本版内容

与 1.4.3 功能一致，仅版本号递增。用途是给已安装 1.4.3 的设备提供一个可更新的目标，
验证完整的应用内升级链路：

1. 检查更新 → 发现 1.4.4
2. 下载 20 MB → SHA-256 / 包名 / 签名校验
3. 授权 → 系统安装器确认
4. 覆盖安装 → 数据保留 → 结果回调

## 验证要点

- 安装被取消时，弹窗应显示「更新未完成」并可重试，不再停在「正在打开安装器」。
- 重试应直接进入安装器，不再重新下载。
- 升级完成后，记录、照片、设置、小组件与提醒均应保留。

## 说明

- 数据库 v2，无迁移；签名不变，可覆盖安装。
