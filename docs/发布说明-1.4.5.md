# 小福日常 1.4.5 发布说明

> 发布日期：2026-11-27
> 版本：`1.4.5`（versionCode 19）
> 平台：compileSdk 37 / **targetSdk 34**

## 本版内容

- `targetSdk` 由 37 调整为 34。
- 其余功能与 1.4.3 一致。

## 原因

真机验证发现，MIUI/HyperOS 的应用安装器在**会话安装**（应用内更新）时额外做了一次 SDK 校验：

```
MIUIPI_InstallStart: blocked session install because sdk version too low
```

当 APK 的 `targetSdk` 高于设备系统版本（本机 Android 14 / API 34，APK 为 37）时，
安装器会在拉起确认页的瞬间静默结束会话，客户端收到 `STATUS_FAILURE_ABORTED`，
表现为"安装已取消"。该拦截与"安装未知应用"权限无关，`adb install` 不受影响。

个人自用、不上架应用商店，因此取 `targetSdk 34` 换取升级可用性；
`compileSdk` 仍为 37，编译与 API 使用不受影响。

## 验证要点

- 在 Android 14 设备上从 1.4.3 检查更新到 1.4.5，应能正常进入系统安装确认页并完成覆盖安装。
- 若仍被拦截，则说明该校验取的是发起方（旧版本）的 targetSdk，需要先用本版覆盖安装一次。
