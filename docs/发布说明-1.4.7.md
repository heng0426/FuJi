# 小福日常 1.4.7 发布说明

> 发布日期：2026-11-27
> 版本：`1.4.7`（versionCode 21）
> 平台：compileSdk 37 / targetSdk 34

## 本版修复两个安装结果问题

### 1. 装好了却提示「安装已取消」（vivo 实测）

应用自我更新时，系统会在安装前后派发 `STATUS_FAILURE_ABORTED`（提交会话的进程即将被替换），
但安装实际已完成。旧逻辑把回调状态当作唯一判据，于是出现"更新成功却弹更新未完成"。

现在改为**以版本号自证**：

- 安装结果回调先比对「当前已安装版本」与「目标版本」，已达到即按成功处理；
- 启动时消费安装结果同样先比版本，版本达标则忽略残留的失败信息；
- 失败提示只在"版本确实没上去"时出现。

### 2. ROM 拦截应用内安装时无路可走（MIUI 实测）

小米 11（Android 14 / HyperOS）上，安装器对应用内发起的安装有一条额外校验：

```
MIUIPI_InstallStart: blocked session install because sdk version too low
```

`targetSdk` 降到 34 后仍未解除，说明校验对象不是 `targetSdk`（很可能与 compileSdk 37 有关）。
`file://` 与无效 `content://` 路径均被安装器直接拒绝。

本版不再尝试绕过该校验，改为给出确定可用的出路：

- 拦截发生时弹窗标题变为「这个机型需要手动安装」，主按钮为「保存并打开」；
- 点击后把已校验的安装包保存到 `下载/小福日常/小福日常-vX.Y.Z.apk`（MediaStore，公开可读）；
- 同时尝试用 `FileProvider` + `ACTION_VIEW` 直接拉起系统安装器；
- 若安装页仍未出现，按提示从「文件管理 → 下载 → 小福日常」点开安装包即可，数据保留。

新增 `FileProvider`（`com.xiaofu.daily.fileprovider`，`exported=false`，仅暴露 `filesDir/update/`），
不扩大对外可读范围。

## 影响面

- 仅涉及升级模块：`InstallResultReceiver`、`UpdateManager`、`UpdateStore`、`ApkInstaller`，
  新增 `ApkExporter`、`res/xml/file_paths.xml`、清单中的 provider 声明。
- 不涉及数据库、权限（`INTERNET` / `REQUEST_INSTALL_PACKAGES` 与 1.4.0 相同）与业务逻辑。

## 验证要点

- vivo：从 1.4.6 升级到 1.4.7，安装完成后打开应提示「已更新到 1.4.7」，不再出现「安装已取消」。
- 小米 11（Android 14）：点更新后若仍被拦截，应显示「这个机型需要手动安装」；
  点「保存并打开」后检查 `下载/小福日常/` 是否出现安装包，并能从文件管理器完成安装。
- 正常机型：升级链路与 1.4.6 一致。
