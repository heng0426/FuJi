# 小福日常 1.5.1 发布说明

> 发布日期：2026-11-27
> 版本：`1.5.1`（versionCode 25）
> 平台：compileSdk 37 / targetSdk 34

## 本版内容

### 加餐类型可自定义

「记加餐 / 编辑加餐」里的类型标签从硬编码改成标签库，与「药品名」「疫苗名称」同一套机制：

- **新增**：末尾「自定义」按钮，输入即添加（最多 20 字），添加后自动选中。
- **删除**：长按任意标签，弹出确认后删除；已保存的历史记录不受影响。
- **持久化**：存 `settings` 表的 `snack_type_tags` 键，随备份导出/导入同步。
- **默认值调整**：`冻干 / 罐头 / 猫条 / 其他`（原为 `冻干 / 罐头 / 零食 / 自制 / 其他`，
  即新增「猫条」，移除「零食」与「自制」）。

### 兼容旧记录

历史记录里若存有「零食」「自制」等已不在标签库的类型，编辑该记录时会把原类型临时
并入显示并保持选中，不会出现"看不到当前值"或保存后丢失的情况。

## 涉及文件

| 文件 | 改动 |
|---|---|
| `data/RecordRepository.kt` | 新增 `SettingsKeys.SNACK_TYPE_TAGS` 与默认值 |
| `ui/today/TodaySheets.kt` | 类型标签改为 `FlowRow` + 长按删除 + 自定义入口 |

复用现有的 `nameTags` / `addNameTag` / `removeNameTag`，未新增存储结构，不需要数据库迁移。

## 验证要点

- 新装或升级后首次打开「记加餐」，类型应为：冻干、罐头、猫条、其他、自定义。
- 长按「罐头」→ 确认删除 → 标签消失；重开弹层仍不存在（已落库）。
- 点「自定义」→ 输入「主食罐」→ 添加后自动选中，并出现在标签行。
- 编辑一条旧的「零食」加餐记录：类型行临时出现「零食」且处于选中态。
- 备份导出再导入后，自定义类型仍在。
