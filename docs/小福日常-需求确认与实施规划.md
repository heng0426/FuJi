## 0. 项目定位与决策记录

**一句话定位**：单宠（橘猫"小福"）日常健康与生活记录工具，核心体验是"3 秒内记一笔"，核心价值是"喝水量、进食量、体重趋势、驱虫/疫苗到期"一眼可查。

### 0.1 已确认的关键决策

| # | 决策项 | 结论 |
|---|--------|------|
| D1 | 宠物档案 | 单宠，界面无切换；数据模型预留 `pet_id`，未来扩多宠免迁移 |
| D2 | 存储与同步 | 纯本地 Room/SQLite，无账号无后端；手动导出备份列入 v1.1 |
| D3 | 技术栈 | Kotlin + Jetpack Compose + Material 3 原生开发，真机调试（无模拟器环境） |
| D4 | 提醒 | v1 含本地通知：驱虫/疫苗到期前 3 天（T-3）与当天（T-0）各一次 |
| D5 | 记录粒度 | 事件式打点：每次行为一条带时间戳的记录，单条可增删改；首页当日自动汇总 |
| D6 | 首页形态 | 混合式：今日概览卡 + 快捷记录按钮组 + 当日时间线（无限上滑回溯全部历史） |
| D7 | 主导航 | 底部四 Tab：「今日」「日历」「记录」「我的」 |
| D8 | 喝水计量 | 按 ml 弹窗输入，**记忆上次输入值**作为预填；汇总显示 ml，不显示次数 |
| D9 | 进食计量 | 按"份"计，可设每份克重；汇总显示"x 份 x 克"；单击快捷按钮 = +1 份主粮，**长按弹窗**可设份数与每份克重并实时统计本次总克数 |
| D10 | 异常分类 | 预设标签 + **支持自定义添加分类** |
| D11 | 主题 | 橘白配色（橘猫主题），暖橙 primary；Material 3 + 深色模式（v1） |

### 0.2 第 2 轮访谈中按推荐采纳的项（显式标注，便于推翻）

| 项 | 采纳的推荐 |
|----|-----------|
| 驱虫周期 | 默认内驱 90 天 / 外驱 30 天（设置可改）；下次到期 = 记录日期 + 周期，可手动改写 |
| 疫苗提醒 | 不预设周期；记录时手动填"下次接种日期"（选填，含 1 年 / 3 年快捷选项），填了才提醒 |
| 时间线深度 | 无限上滑回溯全部历史，按日期分组倒序；跳转任意日期走「日历」页 |
| 删除保护 | 详情页内删除 + Snackbar 撤销（5 秒），不用确认弹窗 |
| 补录 | 所有记录的日期时间均可修改；日历页选中任意日期可直接新增该日记录 |
| 档案字段 | 名字（默认"小福"）、生日、品种、性别、照片，除名字外全部选填 |

## 1. 功能清单

### 1.1 核心功能（v1）

#### F1 · 今日首页

**信息结构（自上而下三层，密度递增）：**

1. **今日概览卡**（看一眼）
   - 今日喝水：`xxx ml`
   - 今日进食：`主粮 x份x克 · 加餐 x份x克`
   - 最近体重：`x.x 斤`（今天 / n 天前），点击可快速补记体重
   - 到期提醒条：未来 3 天内有驱虫/疫苗到期时，显示倒计时 chip（点击跳转对应记录）
2. **快捷记录按钮组**（3 秒记一笔）
   - `+喝水` → 弹窗输入 ml（预填上次值）
   - `+喂食` → 单击 = 快捷记 1 份主粮（当前每份克重）；长按 = 喂食弹窗
   - `+加餐` → 喂食弹窗（加餐态）
   - `+更多` → 展开：体重 / 驱虫 / 疫苗 / 异常 四个入口
3. **当日时间线**（今天发生了什么）
   - 当日全部记录按时间倒序，条目显示类型图标 + 摘要 + 时间
   - 无限上滑回溯全部历史，按日期分组（"今天 / 昨天 / M月d日 EEE"）
   - 点击任一条 → 详情，可编辑、可删除

#### F2 · 喝水记录

| 要素 | 规格 |
|------|------|
| 录入 | 点 `+喝水` 弹底部弹窗：数字输入，**预填上次输入值**；确认即存 |
| 字段 | 时间（默认当前，可改）、ml 数值 |
| 汇总 | 首页概览与日历按日累计 ml |
| 编辑/删除 | 时间线点击 → 详情页操作，删除 Snackbar 撤销 5 秒 |

#### F3 · 喂食记录（主粮 + 加餐）

| 要素 | 规格 |
|------|------|
| 快捷通道 | 单击 `+喂食` = 立即记 1 份主粮（使用"当前每份克重"），Snackbar 撤销 |
| 详细通道 | 长按 `+喂食` 或单击 `+加餐` → 喂食弹窗：主粮/加餐切换、份数步进（0.5 份步进，支持半份）、每份克重（预填当前值，修改后同步为全局当前值）、**本次总克数实时计算显示** |
| 加餐标签 | 冻干 / 罐头 / 零食 / 自制 / 其他（选填，记住上次选择） |
| 字段 | 时间、餐类（主粮/加餐）、份数、每份克重、总克数（存库冗余，防设置变更改写历史）、加餐类型（选填）、备注（选填） |
| 汇总 | 首页按日汇总"x 份 x 克"，主粮加餐分列；跨日不受每份克重设置变更影响 |
| 设置 | 「我的」页喂养设置：全局"每份克重"当前值（默认 15g，可改） |

#### F4 · 体重记录

| 要素 | 规格 |
|------|------|
| 定位 | 按需记录，非每日必填 |
| 录入 | 概览卡点击或 `+更多` 进入：数值输入（斤，0.1 斤步进）、日期可改 |
| 展示 | 概览卡显示最近一次；「我的」或记录详情显示**体重趋势折线图**（v1 自绘 Canvas，无第三方依赖） |

#### F5 · 驱虫日历（内驱 / 外驱）

| 要素 | 规格 |
|------|------|
| 录入 | 日期（默认今天）、类型（内驱/外驱）、药品名（选填）、备注（选填）、下次到期日（自动 = 日期 + 周期，可手动改写） |
| 周期 | 默认内驱 90 天 / 外驱 30 天，「我的」页可改 |
| 展示 | 首页到期提醒条（T-3 内）；日历页到期标记；记录页内驱/外驱分别倒序展示，头部显示"下次到期：x 月 x 日（还有 n 天 / 已超期 n 天）" |
| 提醒 | T-3 与 T-0 各一次本地通知 |

#### F6 · 疫苗接种记录

| 要素 | 规格 |
|------|------|
| 字段 | 接种日期、疫苗名称、备注（选填）、下次接种日期（选填，提供"1 年后 / 3 年后"快捷选项） |
| 提醒 | 仅当"下次接种日期"已填写时，T-3 与 T-0 各一次通知 |
| 展示 | 倒序列表；首页到期提醒条（T-3 内）；日历页到期标记 |

#### F7 · 异常情况记录

| 要素 | 规格 |
|------|------|
| 分类 | 预设标签：呕吐 / 腹泻 / 精神不佳 / 食欲不振 / 咳嗽 / 外伤 / 体温异常 / 其他；**支持自定义添加新标签**（输入即建，持久化到标签库） |
| 字段 | 时间、分类、严重程度（轻/中/重，选填）、文字备注（选填）、照片（选填，最多 3 张） |
| 照片 | 系统相册选取，压缩后存应用私有目录；时间线缩略图展示 |
| 展示 | 时间线高亮样式（区别于日常记录）；记录页可按分类筛选 |

#### F8 · 日历页

- 月历视图：有记录的日子打点标记（普通记录灰点 / 异常记录警示点 / 驱虫疫苗到期橙色标记）
- 点选任意日期 → 该日记录列表（复用时间线组件）+「新增该日记录」按钮（补录入口）
- 左右切换月份；"回到今天"快捷按钮

#### F9 · 记录页（类型导向的历史）

- 顶部类型筛选 chips：全部 / 喝水 / 喂食 / 体重 / 驱虫 / 疫苗 / 异常
- 列表倒序展示所选类型全部历史，点击进详情
- 驱虫、疫苗类型下展示"下次到期"头部信息

#### F10 · 我的页

- **宠物档案卡**：照片、名字（默认"小福"）、品种、性别、生日（自动计算年龄展示）
- **喂养设置**：每份克重当前值
- **驱虫周期设置**：内驱 / 外驱默认周期天数
- **提醒设置**：通知总开关、提前提醒天数（默认 3 天）
- 关于（版本信息）；备份入口 v1.1 预留占位

#### F11 · 基础能力

- **本地通知**：WorkManager 每日调度检查到期项；Android 13+ 运行时申请 `POST_NOTIFICATIONS`
- **深色模式**：跟随系统，Material 3 明暗双主题全量适配
- **数据保护**：删除仅 Snackbar 撤销（5 秒），无二次弹窗；Room 数据本地持久化，覆盖安装（`adb install -r`）不丢数据

### 1.2 可选功能（明确价值与优先级）

| 功能 | 价值 | 优先级 |
|------|------|--------|
| 数据导出 / 本地备份（JSON） | 用户数据安全底线；换机/清数据前可自救 | **v1.1 · 高** |
| 桌面小组件（不打开 App 一键记喝水/喂食） | 高频记录路径再缩短；小组件是宠物类 App 留存利器 | **v1.1 · 中** |
| 喝水 / 进食周报图表（近 7 天柱状图） | 健康趋势可视化，辅助发现食欲异常 | **v1.1 · 中** |
| 照片墙（异常照片相册式浏览） | 就医时快速翻查证据照片 | **v2.0 · 中** |
| 兽医就诊记录（医院 / 诊断 / 处方） | 与疫苗/异常记录联动，形成完整医疗档案 | **v2.0 · 中** |
| 多宠支持 | `pet_id` 已预留，加切换器即可 | **远期 · 低**（有第二只宠物时再启动） |
| 云同步 / 账号 | 换机数据迁移体验，但引入账号体系成本高 | **远期 · 低**（导出备份已覆盖主要诉求） |

**数据模型草案（评审对象）：**

```
profile:      id, name(默认"小福"), birthday?, breed?, gender?, photo_path?
records:      id, pet_id(=1), type(WATER|FOOD|WEIGHT|DEWORM|VACCINE|ANOMALY),
              occurred_at, note?, created_at, updated_at,
              -- 类型专属列（均可空，按 type 取用）：
              amount_ml                      -- 喝水
              meal_kind(MAIN|SNACK), serving_count, grams_per_serving,
              total_grams, snack_type?       -- 喂食（total_grams 存库冗余）
              weight_kg                      -- 体重
              deworm_kind(INTERNAL|EXTERNAL), medicine?, next_due_date?  -- 驱虫
              vaccine_name, next_due_date?   -- 疫苗
              anomaly_category, severity(LIGHT|MEDIUM|HEAVY)?            -- 异常
record_photos: id, record_id, file_path
anomaly_tags:  id, name, is_preset
settings:      key, value   -- serving_grams(默认15g)、deworm_internal_days(90)、
                            -- deworm_external_days(30)、notify_days_ahead(3)、notify_enabled
```

> 单表理由：时间线聚合、日历打点、按日汇总均天然单表高效；六类专属列总量约 12 个，可控。分表方案（六表 + UNION）作为备选，评审时对比后定。

## 附 A · 页面结构与跳转关系

```
底部导航
├─ 今日（首页）
│   ├─ 概览卡 ──点击体重区──→ 体重录入页
│   ├─ 到期提醒条 ──点击──→ 记录页(对应类型筛选)
│   ├─ +喝水 ──→ 喝水弹窗（底部）
│   ├─ +喂食（单击/长按）──→ 快捷记录 / 喂食弹窗（底部）
│   ├─ +加餐 ──→ 喂食弹窗·加餐态（底部）
│   ├─ +更多 ──→ 体重 / 驱虫 / 疫苗 / 异常 录入页
│   └─ 时间线条目 ──点击──→ 详情页（编辑 / 删除 / 改时间）
├─ 日历
│   ├─ 选中日期 ──→ 该日记录列表（复用时间线）+「新增该日记录」
│   └─ 到期标记 ──点击──→ 对应记录详情
├─ 记录
│   ├─ 类型筛选 chips（全部/喝水/喂食/体重/驱虫/疫苗/异常）
│   └─ 列表条目 ──点击──→ 详情页
└─ 我的
    ├─ 宠物档案卡 ──→ 档案编辑
    ├─ 喂养设置 / 驱虫周期设置 / 提醒设置
    └─ 关于 · 备份（v1.1 占位）
```

## 附 B · 六类记录录入流程（统一模式：点击 → 录入 → 确认 → Snackbar）

| 类型 | 入口 | 形态 | 必填 | 耗时目标 |
|------|------|------|------|----------|
| 喝水 | `+喝水` | 底部弹窗，预填上次值 | ml 数 | 3 秒 |
| 主粮 | `+喂食` 单击 | 无弹窗，直接记 1 份 | — | 1 秒 |
| 主粮/加餐详细 | `+喂食` 长按 / `+加餐` | 底部弹窗，实时总克数 | 份数 | 8 秒 |
| 体重 | 概览卡 / `+更多` | 全屏录入页 | kg 数 | 8 秒 |
| 驱虫 | `+更多` | 全屏录入页 | 类型 | 10 秒 |
| 疫苗 | `+更多` | 全屏录入页 | 疫苗名称 | 10 秒 |
| 异常 | `+更多` | 全屏录入页（分类+照片） | 分类 | 15 秒 |
