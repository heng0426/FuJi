## 0. 项目定位与决策记录

**一句话定位**：单宠（橘猫"小福"）日常健康与生活记录工具，核心体验是"3 秒内记一笔"，核心价值是"喝水量、进食量、体重趋势、驱虫/疫苗到期"一眼可查。

### 0.1 已确认的关键决策

| # | 决策项 | 结论 |
|---|--------|------|
| D1 | 宠物档案 | 单宠，界面无切换；数据模型预留 `pet_id`，未来扩多宠免迁移 |
| D2 | 存储与同步 | 纯本地 Room/SQLite，无账号无后端；手动导出备份列入 v1.1 |
| D3 | 技术栈 | Kotlin + Jetpack Compose + Material 3 原生开发，真机调试（无模拟器环境） |
| D4 | 提醒 | v1 含本地通知：驱虫/疫苗到期前 3 天（T-3）与当天（T-0）各一次 |
| D5 | 记录粒度 | 事件式打点：每次行为一条带时间戳的记录，单条可增删改；首页当日自动汇总 |
| D6 | 首页形态 | 混合式：今日概览卡 + 快捷记录按钮组 + 当日时间线（无限上滑回溯全部历史） |
| D7 | 主导航 | 底部四 Tab：「今日」「日历」「记录」「我的」 |
| D8 | 喝水计量 | 按 ml 弹窗输入，**记忆上次输入值**作为预填；汇总显示 ml，不显示次数 |
| D9 | 进食计量 | 按“份”计，**每份克重与份数均自动记忆上次值**；份数为 **1–20 的整数**（不再支持 0.5）；单击快捷按钮直接打开喂食弹窗；内置早餐 3 份/晚饭 4 份预设并支持自定义，使用预设不改变默认份数 |
| D10 | 异常分类 | 预设标签 + **支持自定义添加分类** |
| D11 | 主题 | 橘白配色（橘猫主题），暖橙 primary；Material 3；**跟随系统 / 浅色 / 深色三态可选**，选择持久化 |

### 0.2 第 2 轮访谈中按推荐采纳的项（显式标注，便于推翻）

| 项 | 采纳的推荐 |
|----|-----------|

## 1. 功能清单

### 1.1 核心功能（v1）

#### F1 · 今日首页

**信息结构（自上而下三层，密度递增）：**

1. **今日概览卡**（看一眼）
   - 今日喝水：`xxx ml`
   - 今日进食：主粮常驻；加餐仅在当日有记录时显示（淡入 + 展开/收起动画）
   - 最近体重：`x.x 斤`（今天 / n 天前），点击可快速补记体重
   - 到期提醒条：未来 3 天内有驱虫/疫苗到期时，显示倒计时 chip（点击跳转对应记录）
2. **快捷记录按钮组**（3 秒记一笔）
   - `+喝水` → 弹窗输入 ml（预填上次值）
   - `+喂食` → 单击直接打开喂食弹窗（主粮）；份数/克重预填上次值
   - `+加餐` → 喂食弹窗（加餐态）
   - `+更多` → 展开：体重 / 驱虫 / 疫苗 / 异常 四个入口
3. **当日时间线**（今天发生了什么）
   - 当日全部记录按时间倒序，条目显示类型图标 + 摘要 + 时间
   - 无限上滑回溯全部历史，按日期分组（今天 / 昨天 / yyyy年M月d日 · EEE）
   - 点击任一条 → 详情，可编辑、可删除；长按进入多选批量删除（顶栏吸顶）

#### F2 · 喝水记录

| 要素 | 规格 |
|------|------|
| 录入 | 点 `+喝水` 弹底部弹窗：数字输入，**预填上次输入值**；确认即存 |
| 字段 | 时间（默认当前，可改）、ml 数值 |
| 汇总 | 首页概览与日历按日累计 ml |
| 编辑/删除 | 时间线点击 → 详情页操作，删除 Snackbar 撤销 5 秒 |

#### F3 · 喂食记录（主粮 + 加餐）

| 要素 | 规格 |
|------|------|
| 入口 | 首页「喂食」= 主粮记录；「加餐」= 加餐记录；单击直接打开弹窗，**弹窗内不再提供主粮/加餐切换** |
| 份数 | **整数 1–20**，默认预填上次保存值；已移除 0.5 份步进与“单击记 1 份”快捷通道 |
| 每份克重 | 预填上次值（首次 15g），1–200 可调；「我的」页不再提供全局克重设置 |
| 常用预设 | 内置早餐 3 份、晚饭 4 份；支持自定义名称/份数（横向滚动展示）；长按自定义预设删除；点预设立即记录，**不改变默认份数** |
| 加餐标签 | 冻干 / 罐头 / 零食 / 自制 / 其他（选填，记住上次选择） |
| 字段 | 时间、餐类（主粮/加餐）、份数、每份克重、总克数（存库冗余，防设置变更改写历史）、加餐类型（选填）、备注（选填） |
| 汇总 | 首页按日汇总“x 份 x 克”，主粮/加餐分列；加餐仅在当日有记录时显示，带出现/收起动画 |
| 旧数据兼容 | 历史 0.5 份不再保留：数据库打开时四舍五入为整份（0.5→1）；新保存份数按整数处理 |

#### F4 · 体重记录

| 要素 | 规格 |
|------|------|
| 定位 | 按需记录，非每日必填 |
| 录入 | 概览卡点击或 `+更多` 进入：数值输入（斤，0.1 斤步进），默认预填上次体重；日期可改 |
| 展示 | 概览卡显示最近一次；「我的」或记录详情显示**体重趋势折线图**（v1 自绘 Canvas，无第三方依赖） |

#### F5 · 驱虫日历（内驱 / 外驱）

| 要素 | 规格 |
|------|------|
| 录入 | 日期（默认今天）、类型（内驱/外驱）、药品名（选填）、备注（选填）、下次到期日（自动 = 日期 + 周期，可手动改写） |
| 周期 | 默认内驱 90 天 / 外驱 30 天，「我的」页可改 |
| 展示 | 首页到期提醒条（T-3 内）；日历页**紫色圆环**标记（仅圆环，不画到期点）；记录页驱虫筛选下显示倒计时卡；选中到期日时当天记录首条显示“驱虫到期”信息卡 |
| 提醒 | T-3 与 T-0 各一次本地通知 |

#### F6 · 疫苗接种记录

| 要素 | 规格 |
|------|------|
| 字段 | 接种日期、疫苗名称、备注（选填）、下次接种日期（选填，提供"1 年后 / 3 年后"快捷选项） |
| 提醒 | 仅当"下次接种日期"已填写时，T-3 与 T-0 各一次通知 |
| 展示 | 倒序列表；首页到期提醒条（T-3 内）；日历页**青色圆环**标记；记录页疫苗筛选下显示倒计时卡；选中到期日首条显示“疫苗到期” |

#### F7 · 异常情况记录

| 要素 | 规格 |
|------|------|
| 分类 | 预设标签：呕吐 / 腹泻 / 精神不佳 / 食欲不振 / 咳嗽 / 外伤 / 体温异常 / 其他；**支持自定义添加新标签**（输入即建，持久化）；自定义标签长按可删除，预设标签不可删 |
| 字段 | 时间、分类、严重程度（轻/中/重，选填）、文字备注（选填）、照片（选填，最多 3 张） |
| 照片 | 系统相册选取，压缩后存应用私有目录；时间线缩略图展示；详情弹窗全量展示分类/程度/备注/照片 |
| 展示 | 时间线高亮样式（区别于日常记录）；记录页可按分类筛选 |

#### F8 · 日历页

- 月历视图：跟手左右滑动翻月（`HorizontalPager`），左右箭头同步支持动画切月。
- 日期标记：有记录灰点 / 异常红点；**驱虫紫色圆环 / 疫苗青色圆环**（不再额外画到期小点）。
- 记录小点随当前页即时加载，滑到任意月份无需先点日期。
- 点选任意日期 → 该日记录列表；若为驱虫/疫苗到期日，列表首条显示到期信息卡（标题、药品/备注、到期日）。
- 右上角「+」补记该日记录；点月份标题可**手动输入 `yyyy-MM-dd`** 跳转（格式校验，联动分页）。
- 日历卡右下角（图例最右侧）提供「今天」按钮。
- 日期标题显示完整年月日；今天/昨天保留相对标签。

#### F9 · 记录页（类型导向的历史）

- 顶部类型筛选 chips：全部 / 喝水 / 喂食 / 体重 / 驱虫 / 疫苗 / 异常。
- **长按 chip 可拖动排序**，越过相邻标签自动避让，松手生效并持久化；「全部」固定首位。
- 列表倒序展示所选类型全部历史，点击进详情。
- 筛选驱虫/疫苗时，顶部显示对应到期倒计时卡；「全部」显示全部到期卡。
- 长按记录进入多选，支持批量删除（二次确认）；多选顶栏吸顶，返回键退出。

#### F10 · 我的页

- **宠物档案卡**：照片、名字（默认“小福”）、品种、性别、生日（自动计算年龄展示）。
- **驱虫周期设置**：内驱 / 外驱默认周期天数。
- **提醒设置**：通知总开关、提前提醒天数（默认 3 天）、提醒小时（默认 09:00）。
- **外观**：跟随系统 / 浅色 / 深色，选择持久化并同步系统栏图标。
- 体重趋势图、关于（版本信息）、首次使用引导。
- 不再提供「喂养 · 每份克重」设置项（克重由喂食弹窗记忆）。

#### F11 · 基础能力

- **本地通知**：WorkManager 每日调度检查到期项；Android 13+ 运行时申请 `POST_NOTIFICATIONS`
- **主题**：跟随系统 / 浅色 / 深色三态；Material 3 明暗双主题全量适配，系统栏图标随主题反色
- **数据保护**：单条删除 Snackbar 撤销（5 秒）；批量删除二次确认且不可撤销；Room 数据本地持久化，覆盖安装（`adb install -r`）不丢数据

### 1.2 可选功能（明确价值与优先级）

| 功能 | 价值 | 优先级 |
|------|------|--------|
| 数据导出 / 本地备份（JSON） | 用户数据安全底线；换机/清数据前可自救 | **v1.1 · 高** |
| 桌面小组件（不打开 App 一键记喝水/喂食） | 高频记录路径再缩短；小组件是宠物类 App 留存利器 | **v1.1 · 中** |
| 喝水 / 进食周报图表（近 7 天柱状图） | 健康趋势可视化，辅助发现食欲异常 | **v1.1 · 中** |
| 照片墙（异常照片相册式浏览） | 就医时快速翻查证据照片 | **v2.0 · 中** |
| 兽医就诊记录（医院 / 诊断 / 处方） | 与疫苗/异常记录联动，形成完整医疗档案 | **v2.0 · 中** |
| 多宠支持 | `pet_id` 已预留，加切换器即可 | **远期 · 低**（有第二只宠物时再启动） |
| 云同步 / 账号 | 换机数据迁移体验，但引入账号体系成本高 | **远期 · 低**（导出备份已覆盖主要诉求） |

**数据模型草案（评审对象）：**

```
profile:      id, name(默认"小福"), birthday?, breed?, gender?, photo_path?
records:      id, pet_id(=1), type(WATER|FOOD|WEIGHT|DEWORM|VACCINE|ANOMALY),
              occurred_at, note?, created_at, updated_at,
              -- 类型专属列（均可空，按 type 取用）：
              amount_ml                      -- 喝水
              meal_kind(MAIN|SNACK), serving_count, grams_per_serving,
              total_grams, snack_type?       -- 喂食（total_grams 存库冗余）

              deworm_kind(INTERNAL|EXTERNAL), medicine?, next_due_date?  -- 驱虫
              vaccine_name, next_due_date?   -- 疫苗
              anomaly_category, severity(LIGHT|MEDIUM|HEAVY)?            -- 异常
record_photos: id, record_id, file_path
anomaly_tags:  id, name, is_preset
settings:      key, value   -- serving_grams(默认15g)、deworm_internal_days(90)、
                            -- deworm_external_days(30)、notify_days_ahead(3)、notify_enabled
```

> 单表理由：时间线聚合、日历打点、按日汇总均天然单表高效；六类专属列总量约 12 个，可控。分表方案（六表 + UNION）作为备选，评审时对比后定。

## 附 A · 页面结构与跳转关系（当前实现）

```
底部导航
├─ 今日（首页）
│   ├─ 概览卡 ──点击体重区──→ 体重录入页（预填上次值）
│   ├─ 到期提醒条 ──点击──→ 记录页（对应类型筛选）
│   ├─ +喝水 ──→ 喝水弹窗（预填上次 ml，无说明小字）
│   ├─ +喂食 ──→ 喂食弹窗（主粮；份数/克重记忆；预设）
│   ├─ +加餐 ──→ 加餐弹窗（加餐；无主粮/加餐切换）
│   ├─ +更多 ──→ 体重 / 驱虫 / 疫苗 / 异常 录入页
│   └─ 时间线条目 ──点击──→ 详情；长按──→ 多选（顶栏吸顶，批量删除）
├─ 日历
│   ├─ 跟手横滑 / 箭头 ──→ 切换月份
│   ├─ 月份标题 ──→ 手动输入日期跳转
│   ├─ 选中日期 ──→ 当日记录 + 到期日首行到期卡；右上角 + 补记
│   └─ 卡右下角「今天」──→ 回到今日
├─ 记录
│   ├─ 类型 chips ──长按拖动──→ 调整顺序并持久化
│   ├─ 筛选驱虫/疫苗 ──→ 顶部显示对应倒计时卡
│   └─ 记录 ──点击详情 / 长按多选批量删除（吸顶栏）
└─ 我的
    ├─ 宠物档案卡 ──→ 档案编辑
    ├─ 驱虫周期 / 提醒 / 外观（跟随系统·浅色·深色）
    └─ 体重趋势 · 关于 · 首次引导
```

## 附 B · 六类记录录入流程（当前实现）

| 类型 | 入口 | 形态 | 必填 | 耗时目标 |
|------|------|------|------|----------|
| 喝水 | `+喝水` | 底部弹窗，预填上次 ml | ml 数 | 3 秒 |
| 主粮 | `+喂食` 单击 | 底部弹窗：整数份数 + 克重 + 预设，预填上次值 | 份数 | 5 秒 |
| 加餐 | `+加餐` 单击 | 底部弹窗（加餐态，无切换） | 份数 | 5 秒 |
| 体重 | 概览卡 / `+更多` | 全屏录入页，预填上次体重 | 斤数 | 8 秒 |
| 驱虫 | `+更多` | 全屏录入页 | 类型 | 10 秒 |
| 疫苗 | `+更多` | 全屏录入页 | 疫苗名称 | 10 秒 |
| 异常 | `+更多` | 全屏录入页（分类 + 照片 + 删除自定义分类） | 分类 | 15 秒 |
